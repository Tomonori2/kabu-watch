# 意見箱（みんなの声）のはじめかた

所要時間：10分くらい。株価お知らせ・波アプリのときと同じ手順です。

1. Googleドライブで **新しいスプレッドシート** を作り、名前を「株ウォッチ みんなの声」にする
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている文字を全部消し、`iken.gs` の中身を全部貼りつけて保存（💾）
   - 貼ったあと、最後の行に余計な文字（「ら」など）が入っていないか確認
4. 上の関数えらびで **setup** をえらんで「実行」→ 許可の画面で自分のアカウントを選んで許可
   - スプレッドシートに「意見」「投票」「候補」「直したこと」の4枚のシートができればOK
5. 右上の **デプロイ → 新しいデプロイ** → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 出てきた **ウェブアプリのURL**（…/exec で終わる）をコピーして Claude に渡す
   → `index.html` の `KOE_URL` に入れて公開します

## ふだんの使い方

- **意見**シート：届いた声。読んだら「状態」を「読んだ」「直した」に
- **候補**シート：「つぎに作るもの投票」の候補。行を足せばアプリに出ます。作ったら状態を「作った」に
  - 候補IDは英数字だけ（例：chart）。一度出したIDは変えない（票がずれます）
- **直したこと**シート：日付と内容を書くと、アプリの「みんなの声で直したこと」にそのまま出ます

## 気をつけること

- 意見の文そのものはアプリに出ません（あなただけが読みます）。アプリに出るのは「候補」「直したこと」と、意見の**件数**だけ
- 「直したこと」はあなたが書いた文がそのまま公開されます。意見をくれた人の書いた文をそのまま貼らない（個人が分かることが混ざるかもしれないため）
- `iken.gs` を書きかえたら、**デプロイ → デプロイを管理 → 編集 → 新しいバージョン** で出し直しが必要です
